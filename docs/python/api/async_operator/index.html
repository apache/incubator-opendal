delete_many(paths) #

Delete an explicit collection of paths with default delete options.

Notes

This method collects the iterable and converts its Python path objects before deletion starts, using memory proportional to the number of paths. Empty collections do nothing. Paths that do not exist are ignored. Storage or path-validation errors can leave some paths deleted; this operation is not atomic and does not guarantee a single remote request. Use remove_all to recursively delete a path prefix.

Parameters:

Name Type Description Default
paths Iterable[str | PathLike[str]]

The paths to delete. A single path is not accepted.

 required

Returns:

Type Description
Awaitable[None]

An awaitable that completes when deletion finishes.

from_config(config) classmethod #

Create a new AsyncOperator from a typed service config.

The config is an opendal.config.ServiceConfig (e.g. S3Config); its scheme key selects the service, so a static type checker rejects a wrong scheme, a missing required key, an unknown key, and a wrong value type. Non-string values (bool, int, os.PathLike, list) are converted to the string form core consumes.

Parameters:

Name Type Description Default
config ServiceConfig

A service configuration such as opendal.config.S3Config.

 required

Returns:

Type Description
AsyncOperator

The new async operator.

Examples:

1
2
3
4
5
6
import opendal
from opendal.config import S3Config

op = opendal.AsyncOperator.from_config(
    S3Config(scheme="s3", bucket="my-bucket")
)

from_uri(uri, **kwargs) classmethod #

Create a new AsyncOperator from a URI string.

The URI encodes the scheme and configuration in a single string, e.g. memory:// or s3://bucket/path?region=us-east-1. The scheme must belong to a service enabled in this build. Encode service options as query parameters; use urllib.parse.urlencode when building the URI dynamically.

Parameters:

Name Type Description Default
uri str

The URI of the service, including any options as query parameters.

 required
**kwargs dict

Overrides for URI options. Prefer the URI query string.

 {}

Returns:

Type Description
AsyncOperator

The new async operator.

Examples:

1
2
3
4
5
6
7
8
from urllib.parse import urlencode
import opendal

op = opendal.AsyncOperator.from_uri("memory://")
query = urlencode({"region": "us-east-1"})
op = opendal.AsyncOperator.from_uri(
    f"s3://bucket/path?{query}"
)
