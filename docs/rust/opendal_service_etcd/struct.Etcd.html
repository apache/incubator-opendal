Etcd services support.

§Capabilities

Depending on its configuration and the backing system, this service can expose:

  • create_dir
  • stat
  • read
  • write
  • delete
  • list
  • copy
  • rename
  • presign

Inspect the effective capability set with [opendal_core::Operator::info] and [opendal_core::OperatorInfo::capability] after building an operator.

§Configuration

Use crate::EtcdConfig for serializable configuration and this builder’s methods for direct construction. The field and method documentation defines accepted values, defaults, and environment interaction.

For server-authenticated TLS, configure an HTTPS endpoint and ca_path. The server certificate must be trusted by the supplied CA. For mutual TLS, also configure cert_path and key_path; these two paths must always be supplied together.

§Example

§Via Builder

use opendal_core::Operator;
use opendal_core::Result;
use opendal_service_etcd::Etcd;

#[tokio::main]
async fn main() -> Result<()> {
    let mut builder = Etcd::default();

    // this will build a Operator accessing etcd which runs on http://127.0.0.1:2379
    let op: Operator = Operator::new(builder)?;
    Ok(())
}

pub fn ca_path(self, ca_path: &str) -> Self

Set the PEM certificate authority file used to verify the server.

This enables TLS without requiring a client certificate or private key. Use HTTPS endpoints when configuring TLS.

No custom certificate authority is configured by default.

Source

pub fn cert_path(self, cert_path: &str) -> Self

Set the PEM client certificate file used for mutual TLS.

Set this together with Self::key_path. Building an operator with only one of these paths returns [ErrorKind::ConfigInvalid].

No client certificate is configured by default.

Source

pub fn key_path(self, key_path: &str) -> Self

Set the PEM client private key file used for mutual TLS.

Set this together with Self::cert_path. Building an operator with only one of these paths returns [ErrorKind::ConfigInvalid].

No client private key is configured by default.

Source

pub fn max_decoding_message_size(self, size: usize) -> Self

Set the maximum size in bytes of a gRPC response that the etcd client decodes.

default is None, which keeps the etcd client default of 4 MiB
