OpenDAL contracts, Rust core guides, and historical project documents.

Start with concepts for the Rust core API model. specs defines the current portable contracts implemented by OpenDAL. Service and layer authors can continue with internals, while performance covers application tuning. Accepted RFCs in rfcs preserve the decisions and context that led to current designs.
