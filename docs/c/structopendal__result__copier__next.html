Detailed Description

The result type returned by opendal_copier_next().

A copy is driven by calling opendal_copier_next() repeatedly: each call performs one step of the copy until the copy reports completion.

Fields:

  • size: the number of bytes copied in this step; zero on error or completion.
  • has_next: true when the copy made progress and should be driven again by another opendal_copier_next() call; when false and error is null, the copy has completed.
  • error: the error code and message; null when the step succeeds.
